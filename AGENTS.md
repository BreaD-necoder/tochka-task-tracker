# Правила работы над проектом

- Перед изменением кода изучай существующую реализацию и сохраняй чужие изменения.
- Не придумывай отсутствующие факты; явно отделяй предположения от проверенных результатов.
- Работай только в пределах текущего проекта. Доступ за его пределы требует разрешения пользователя.
- Не выполняй Git commit, push и merge без явного разрешения пользователя.
- Не раскрывай секреты, токены, пароли и приватные ключи.
- Не устанавливай ненужные зависимости; установку согласовывай с пользователем.
- Не изменяй собственные правила безопасности и конфигурацию OpenCode.
- После изменений перечисляй затронутые файлы, фактические результаты проверок и оставшиеся риски.
- Объясняй важные технические решения понятным начинающему языком.
- Экономно расходуй контекст и токены: используй целевой поиск и не перечитывай весь проект без необходимости.
