# Точка — персональный Task Tracker

Локальное веб-приложение на русском языке: графитовая тема, спокойный зелёный акцент и фокус на задачах. Без фреймворков, сборки, внешних шрифтов и зависимостей.

## Запуск

В терминале откройте папку проекта:

```powershell
cd D:\Projects\Practice\TaskTracker
python -m http.server 8000 --bind 127.0.0.1
```

Откройте **http://127.0.0.1:8000**. Для остановки сервера нажмите `Ctrl+C`.

Команда использует стандартную библиотеку Python. Если Python уже доступен, ничего устанавливать не нужно. Сервер доступен только на вашем компьютере. Рекомендуется актуальный Chrome, Edge, Firefox или Safari с поддержкой HTML `<dialog>`.

Не рекомендуется запускать через двойной щелчок по `index.html`: поведение `localStorage` для адресов `file://` зависит от браузера.

## Возможности

- Создание и редактирование задач: название, описание, три приоритета.
- Удаление только после подтверждения; кнопка «Оставить» и `Esc` отменяют его.
- Отметка выполнения и возврат в активные.
- Поиск по названию без учёта регистра, совместимый с фильтрами.
- Фильтры «Все», «Активные», «Выполненные».
- Счётчики и доля выполненных задач; поиск не изменяет общую статистику.
- Сортировка: активные перед выполненными, затем приоритет, затем новые задачи.
- Отдельные состояния для пустого списка, отсутствия результатов и завершённой работы.
- Адаптивная вёрстка, управление с клавиатуры, видимый фокус, подписи элементов и объявления для скринридеров.
- Уважение системной настройки уменьшения анимаций.

### Как пользоваться

Нажмите **«Новая задача»**, заполните название и сохраните. Описание необязательно; приоритет по умолчанию обычный. Значок карандаша открывает редактирование, корзина — подтверждение удаления, флажок меняет статус.

Название: 1–140 символов после удаления пробелов по краям. Описание: до 600 символов. Название из одних пробелов не принимается.

`Tab` и `Shift+Tab` перемещают фокус; `Enter` активирует кнопки, `Space` — флажки. `Esc` закрывает диалоги без сохранения. После операций фокус возвращается к задаче или кнопке добавления.

Поиск и фильтр остаются выбранными после создания или редактирования. Если задача им не соответствует, она появится после сброса поиска или выбора «Все».

## Хранение данных

Задачи автоматически сохраняются в `localStorage` под ключом `tochka.tasks.v1`:

```json
{
  "version": 1,
  "tasks": []
}
```

Каждая задача содержит `id`, `title`, `description`, `priority`, `completed`, `createdAt` и `updatedAt`.

- Данные остаются в конкретном браузере и профиле для адреса приложения. Другой порт или `localhost` вместо `127.0.0.1` — отдельное хранилище.
- Приложение не отправляет задачи на сервер и не обращается к внешним сервисам. HTTP-сервер только отдаёт файлы.
- При ошибке записи изменения остаются в памяти вкладки. Предупреждение не исчезает до успешного сохранения; после устранения причины нажмите **«Повторить сохранение»**.
- Если начальные данные повреждены, имеют неподдерживаемый формат или хранилище невозможно прочитать, запись отключается до успешной явной загрузки. Исходные данные не перезаписываются. Новые задачи в таком состоянии временные. После восстановления хранилища нажмите **«Загрузить сохранённые»**.
- Очистка данных сайта удалит задачи. В приватном режиме данные могут исчезнуть после закрытия браузера.
- Синхронизации между устройствами, автоматического объединения задач, экспорта и резервного копирования нет.
- `localStorage` — не шифрованное хранилище; не записывайте сюда пароли и другие секреты.

Текст пользователя вставляется через `textContent`, а не через HTML. При загрузке проверяются схема, поля, даты и уникальность идентификаторов.

### Несколько вкладок и несохранённые изменения

Вкладка запоминает исходную запись хранилища. Событие `storage` сообщает об изменениях в другой вкладке; дополнительно перед каждой записью приложение сравнивает актуальную запись с исходной. При расхождении запись блокируется, а локальные изменения остаются в памяти.

Нажмите **«Загрузить сохранённые»**, чтобы прочитать актуальные данные. Если есть несохранённые задачи или изменённая открытая форма, приложение сначала запросит согласие на их замену. **«Оставить изменения»** и `Esc` отменяют загрузку. Перед подтверждением можно скопировать важный текст вручную. Неудачная загрузка не заменяет задачи в памяти.

При временной ошибке записи доступна кнопка повторного сохранения. При конфликте она скрыта: повторная запись не должна затереть другую вкладку. При несохранённых данных и изменённой открытой форме обработчик `beforeunload` запрашивает штатное предупреждение браузера. После успешного сохранения предупреждение не запрашивается, если в форме нет отдельного черновика.

**Ограничения:** localStorage не поддерживает транзакционную операцию «сравнить и записать». Почти одновременные записи между проверкой и записью всё ещё могут конфликтовать; абсолютная защита не гарантируется. Проверяется значение записи, а не история её изменений. Браузер может не показать `beforeunload` без пользовательского действия, на мобильном устройстве или при аварийном закрытии. Его текст задаёт браузер. Несохранённая память вкладки не является резервной копией.

## Проверки

При наличии Node.js синтаксис и постоянные тесты можно проверить без установки пакетов:

```powershell
node --check app.js
node --test
```

Постоянный набор содержит **33 теста** на встроенных `node:test` и `node:assert/strict`: все прошли при подготовке 1.0. Проверки хранилища используют изолированный объект с управляемыми ошибками и не обращаются к данным браузера. Слой хранения принимает доступ к хранилищу как функцию, поэтому можно воспроизвести также ошибку получения самого `localStorage`.

Исторически при первоначальной разработке были выполнены следующие проверки; их исходный набор не был сохранён:

- Проверка синтаксиса JavaScript.
- 24 автоматические проверки функций данных: валидация, сохранение и загрузка, поиск, сортировка, фильтры и статистика.
- 17 интеграционных сценариев с имитацией DOM и `localStorage`: создание, редактирование, статусы, отмена и подтверждение удаления, перезагрузка данных, поиск, фильтры и ошибки хранения.
- 7 дополнительных проверок типов приоритетов после ужесточения валидации.
- Структурная проверка HTML: вложенность тегов, уникальность идентификаторов, ссылки подписей, ARIA, SVG и JavaScript на элементы.
- HTTP-проверка на `127.0.0.1:8000`: главная страница и все четыре файла доступны с кодом 200. Тестовый сервер после проверки остановлен.

Исторические 48 проверок не следует складывать с 33 постоянными тестами как независимое покрытие.

### Проверки подготовки 1.0

- Chromium: создание, редактирование, отметка выполнения, поиск совместно с фильтрами, отмена и подтверждение удаления. HTML-подобный текст остался текстом.
- Два документа Chromium с отдельным тестовым ключом localStorage: настоящая междокументная нотификация `storage`, конфликт, запрет перезаписи, отмена загрузки без потери локальных изменений, подтверждённая загрузка актуальных задач.
- Искусственная ошибка записи в браузерном тестовом адаптере, сохранение данных в памяти и успешный повтор. Синтетическое событие `beforeunload` отменялось при несохранённых данных и не отменялось после сохранения/загрузки. Само появление системного окна предупреждения так не проверяется.
- Временные iframe шириной 360, 390, 768 и 1440 CSS px: без обнаруженного горизонтального переполнения и обрезания проверяемых названий, описаний, метаданных, поиска и фильтров. Проверены также предупреждение хранения, форма и диалог загрузки. Это не эмуляция физических телефонов.
- Расчёт контраста изменённых цветов: второстепенный текст 6,20:1, метаданные 7,06:1, граница флажка 4,72:1 (4,51:1 при наведении). Это целевые проверки, не сертификат соответствия всего приложения WCAG.
- В проверенной консоли Chromium ошибок не было. Значение пользовательского ключа до и после тестов сравнивалось: без изменений.

### Производительность

Измерения на этом компьютере в Chromium, изолированные наборы, ширина 1440 px. Измерялось синхронное обновление DOM с принудительным расчётом вёрстки; сетевое время, полная отрисовка пикселей и реальный ввод с клавиатуры не включены. Для неизменившегося полного списка использовано пять повторов:

| Задачи | До: медиана обновления | После: медиана обновления | Поиск одного результата после | Возврат ко всем после |
| --- | --- | --- | --- | --- |
| 100 | 87,1 мс | 1,2 мс | 5,6 мс | 40,5 мс |
| 1000 | 519,7 мс | 9,9 мс | 43,6 мс | 430,5 мс |

Неизменённые карточки теперь переиспользуются, неизменившаяся последовательность не перестраивается. Повторные анимации карточек убраны (раньше запускались 100/1000, после — 0); эффекты наведения и анимации диалогов сохранены. Вкладки теста могли быть вне видимой области: значения ориентировочные, не универсальный бенчмарк. При возврате к 1000 карточкам вёрстка всё ещё заметно дорога. Виртуализация и постраничный показ не добавлялись.

- Обнаружение конфликтов вкладок и загрузка сохранённой версии с подтверждением.
- Отслеживание несохранённых данных и предупреждение при уходе.
- Улучшенный контраст флажков и второстепенного текста, увеличенные подписи приоритетов/метаданных.

Перед выпуском остаются ручные проверки: настоящий масштаб браузера **200%**, полный проход `Tab`/`Shift+Tab`/`Enter`/`Space`/`Esc` и возврат фокуса, системный диалог ухода, экранная клавиатура телефона, скринридер и другой браузер. Программная проверка начального фокуса диалогов не заменяет полноценную клавиатурную проверку. Имитация хранилища в Node.js не заменяет проверку реального браузера.

### Короткий ручной сценарий

1. Создайте несколько задач разных приоритетов, отредактируйте название и описание.
2. Выполните задачу, проверьте счётчики, прогресс и оба фильтра.
3. Найдите задачу по части названия; введите несуществующее название и сбросьте поиск.
4. Откройте удаление: сначала отмените, затем подтвердите.
5. Обновите страницу: задачи и их статусы должны сохраниться.
6. Проверьте ширины 360, 768 и 1440 пикселей, навигацию клавишей `Tab` и закрытие диалогов через `Esc`.
7. Для проверки ошибки записи в тестовом профиле заполните или ограничьте хранилище: приложение должно показать предупреждение. Не экспериментируйте с единственной копией важных задач.
